ฟอนต์โมจิ (Moji) — Crafty Font
==============================
ฟอนต์นี้เป็น ALL RIGHTS RESERVED — ไม่ได้แนบมาในโปรเจกต์

วิธีใช้:
1. ดาวน์โหลดฟอนต์โมจิ (เวอร์ชัน Regular ฟรี หรือเต็ม $12) อย่างถูกต้องจาก
   https://craftyfont.gumroad.com/l/mojifont
   หรือ https://www.f0nt.com/release/moji/
2. นำไฟล์ฟอนต์มาตั้งชื่อเป็น  Moji-Regular.ttf
3. วางไว้ในโฟลเดอร์นี้ (public/fonts/Moji-Regular.ttf)
4. เปิดแอป → ตั้งค่า → ฟอนต์ → เลือก "โมจิ"

หมายเหตุ: ถ้าไม่มีไฟล์ ระบบจะใช้ Itim (สไตล์ใกล้เคียง) แทนโดยอัตโนมัติ
